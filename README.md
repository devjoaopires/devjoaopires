**DESENVOLVEDOR FULLSTACK**

<p align="justify">
Sou João Pires, desenvolvedor fullstack com foco na criação de sistemas web, APIs e integrações que unem desempenho, organização e uma boa experiência de uso. Atuo no desenvolvimento de soluções sob medida, transformando regras de negócio em aplicações funcionais, escaláveis e fáceis de manter. Gosto de construir projetos com código limpo, interfaces objetivas e estruturas bem planejadas para resolver problemas reais com eficiência. Busco sempre evoluir tecnicamente, aplicar boas práticas e entregar software com qualidade, clareza e consistência. Meu objetivo é desenvolver soluções modernas e úteis que gerem valor real para pessoas, processos e negócios.
